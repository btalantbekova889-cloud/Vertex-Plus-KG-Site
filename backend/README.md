# Vertex Plus KG — API

Бэкенд для формы заявки на сайте: ASP.NET Core 8 Web API + SQLite (через EF Core).
Принимает заявки с формы на сайте (`index.html`) и сохраняет их в базу.

## Запуск в Visual Studio

1. Откройте `VertexPlusApi.sln` в Visual Studio 2022 (17.8+) или Visual Studio Code с расширением C#.
2. Убедитесь, что установлен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
3. Нажмите **F5** (или ▶ Run) — выберите профиль `https` или `http`.
4. Откроется Swagger UI (`/swagger`), где можно проверить эндпоинты вручную.
5. При первом запуске автоматически создаётся файл базы данных `leads.db` рядом с проектом — миграции не требуются.

По умолчанию API поднимается на:
- `http://localhost:5080`
- `https://localhost:7080`

## Запуск из терминала

```bash
cd backend/VertexPlusApi
dotnet run
```

## Эндпоинты

| Метод | Путь              | Описание                                   |
|-------|--------------------|---------------------------------------------|
| POST  | `/api/leads`        | Создать заявку (имя, телефон, материал, комментарий) |
| GET   | `/api/leads`        | Список заявок, новые сверху (для админки)   |
| GET   | `/api/leads/{id}`    | Получить одну заявку по id                  |

Пример тела запроса для `POST /api/leads`:

```json
{
  "name": "Азамат",
  "phone": "+996 555 12 34 56",
  "material": "Щебень, 10 тонн",
  "comment": "Доставка на объект в Аламедине"
}
```

## Подключение фронтенда

Файл `assets/js/main.js` на сайте отправляет данные формы на адрес,
заданный константой `API_BASE_URL` в начале файла (по умолчанию
`http://localhost:5080`). Если сайт открывается локально просто двойным
кликом (без бэкенда), форма всё равно покажет сообщение об успехе, но заявка
никуда не попадёт — поэтому для реальной работы формы бэкенд должен быть
запущен.

Для продакшена:
1. Опубликуйте API (`dotnet publish`) на сервер/хостинг с поддержкой .NET 8.
2. Замените `API_BASE_URL` в `assets/js/main.js` на реальный адрес API.
3. В `Program.cs` сузьте политику CORS с "разрешить всем" до конкретного домена сайта.

## Структура проекта

```
backend/
├── VertexPlusApi.sln
└── VertexPlusApi/
    ├── Controllers/LeadsController.cs   — эндпоинты /api/leads
    ├── Models/Lead.cs                    — сущность заявки (что хранится в БД)
    ├── Models/LeadCreateRequest.cs       — модель входящего запроса с формы
    ├── Data/AppDbContext.cs              — EF Core DbContext (SQLite)
    ├── Program.cs                        — конфигурация приложения, CORS, Swagger
    └── appsettings.json                  — строка подключения к базе
```
